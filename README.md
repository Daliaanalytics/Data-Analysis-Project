*Project Description*

This project analyzes Superstore sales data to identify key drivers of profitability and the impact of discount strategies on different product categories. The data was cleaned and transformed using Python and Pandas, then visualized through a dashboard.

*Tools Used*:
- Python
- Jupyter Notebook
- Power BI
- Data Visualization
- Business Analysis
  
  *Steps Performed*:
- Data Preparation
  
- Data Cleaning
  
- Feature Engineering
  
- Data Visualization
  
- Dashboard Creation
